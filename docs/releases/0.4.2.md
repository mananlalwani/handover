# Handover 0.4.2

Install the Android APK below to update the existing release-signed app. On the
phone, Updates > Check GitHub releases downloads the signed release; Android still asks
before installing it. The APK uses version code 62, above both 0.4.1 and preview
build 61. Pairing and app data are retained during a normal signed upgrade.

## Changes

- Native Linux Messages and control-center apps, with task-based navigation and
  shared daemon state.
- Improved message history loading, replies, reactions, contact pictures, group
  names, read state, saved search, and attachment composition.
- Phone storage browsing and file or folder downloads from Linux, with original
  filenames, verified bytes, progress, cancellation, and explicit resume. Matching
  builds support files up to 8 GiB and paged directory listings.
- Phone volume controls and explicit Bluetooth call-audio device selection.
- Per-app Android notification forwarding settings, desktop notification actions
  and replies, clipboard history, contacts, and media controls.
- Local device nicknames that survive reconnects and restarts.
- Updated SQLite dependencies, recovery fixes, and installation/upgrade checks.

Use the matching Linux build for the new phone-file and volume controls. Broad
storage browsing needs Android's all-files permission once; sharing one folder
remains available as a narrower option.

## Limits

Bluetooth call audio remains experimental pending physical-phone audibility and
recovery validation. New-conversation creation, remote message deletion, and
outgoing typing are unavailable in the native Google Messages helper. Android
still restricts background clipboard access and other apps' private files.

See the [known limitations](https://github.com/mananlalwani/handover/blob/v0.4.2/docs/KNOWN_LIMITATIONS.md)
and [phone validation checklist](https://github.com/mananlalwani/handover/blob/v0.4.2/docs/phone-validation.md).
