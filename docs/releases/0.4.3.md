# Handover 0.4.3

This release improves the Android app's navigation and notification forwarding
settings. The Android APK uses version code 63 and updates the release-signed
0.4.2 app while retaining pairing and app data.

## Changes

- Notification settings show app icons, bold app names, and smaller package IDs.
  Search filters by app name or package ID as you type.
- Allow all and Block all update every app in the list, including apps outside
  the current search. New apps remain allowed by default. Blocking forwarding
  leaves the notification on the phone.
- The home screen groups phone sharing, laptop controls, and settings. Pages
  share consistent buttons, spacing, and headings.
- Connection fingerprints are on the Connection page. Permission details can be
  expanded, and permission buttons show their current state.
- Returning home restores the previous scroll position. Leaving search closes
  the keyboard, and the app keeps focused fields above the keyboard. Test media
  controls are under Diagnostics.

## Updating

On the phone, open Updates > Check GitHub releases, then Install downloaded
update. Android asks before installing the verified APK. The desktop protocol
is unchanged; these Android improvements work with the 0.4.2 Linux backend.

The [known limitations](https://github.com/mananlalwani/handover/blob/v0.4.3/docs/KNOWN_LIMITATIONS.md)
from 0.4.2 still apply, including experimental Bluetooth call audio and the
unavailable Google Messages operations listed there.
